<objective>
Harden the access-control and OTP-send layer: replace the in-memory OTP rate-limit Map with an atomic Redis counter (INFRA-01), reconcile the OTP digit length so generation and validation agree (AUTH-01), and register JwtAuthGuard globally with a new @Public() decorator so every route is auth-protected by default (INFRA-03). Audit all controllers and mark genuinely public routes.

Purpose: The in-memory Map loses state on deploy and is per-replica, enabling SMS-cost abuse (PITFALLS H3). The per-route guard pattern lets any controller missing both guards sit unprotected (PITFALLS M1) because RolesGuard returns true when no @Roles() is present. Both are default-deny security fixes. This runs in Wave 1 so later auth work (cookie migration in Plan 04, OneID in Plan 06) can assume the global guard exists. OTP length is reconciled here because it lives in the same `auth.service.ts` OTP-send code path the rate-limit refactor rewrites.
Output: Redis-backed OTP throttle, a consistent OTP digit length, and a global default-deny guard with an explicit public-route allowlist.
</objective>
