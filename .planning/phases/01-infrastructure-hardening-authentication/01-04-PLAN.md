<objective>
Migrate the refresh token out of localStorage into an HttpOnly cookie (INFRA-02) — the central XSS-defense win of the phase — and make auth pages reachable without a locale prefix (AUTH-02). The cookie migration spans 5 files across two apps and is easy to half-do into silent 15-minute logouts, so it is treated as one atomic change with a full login→expiry→refresh test.

Purpose: A refresh token in localStorage can be exfiltrated by any XSS (PITFALLS / ASVS V3). Moving it to an HttpOnly cookie (with access token in memory) closes that. AUTH-02 fixes inconsistent redirects on bare `/login`.
Output: HttpOnly refresh cookie end-to-end + locale-prefix redirect for auth routes.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser JS → token storage | XSS-reachable storage vs HttpOnly cookie |
| browser → /api/auth/refresh | Cross-origin credentialed request carrying the refresh cookie |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan | ASVS |
|-----------|----------|-----------|-------------|-----------------|------|
| T-04-01 | Info Disclosure / Spoofing | Refresh token in localStorage exfiltrated via XSS | mitigate | HttpOnly cookie (JS cannot read it); access token short-lived in memory only (ASVS V3) | V3 |
| T-04-02 | Spoofing (CSRF) | Cookie-based refresh forged cross-site | mitigate | `SameSite=lax` + CORS allowlist with `credentials:true` for explicit origins; refresh only via POST; cookie scoped to `path=/api/auth` | V3 |
| T-04-03 | Info Disclosure | Cookie sent over plaintext | mitigate | `secure: true` in production (TLS-only cookie) | V9 |
| T-04-04 | DoS (UX) | Half-migrated cookie causes silent 15-min logout | mitigate | Atomic 5-file change + full login→expiry→refresh checklist; controller spec asserts body has no refreshToken (PITFALLS Pitfall 2) | V3 |
| T-04-SC | Tampering | npm install (cookie-parser, @types/cookie-parser) | mitigate | RESEARCH-approved, slopcheck `[OK]`, official expressjs package; pinned versions cookie-parser 1.4.7 | — |
