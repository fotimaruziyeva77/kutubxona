Make real-time delivery multi-instance-safe (INFRA-07) by wiring the Socket.IO Redis adapter, and activate a NestJS Kafka consumer (INFRA-08) that reads the existing producer topics and routes events to the WebSocket gateway. Both subsystems must degrade gracefully when their backing service is absent.

The Kafka producer currently has no consumer (PITFALLS S4) — events flow to dead infrastructure. A NestJS consumer (Python AI engine is v2-deferred per STATE.md) closes the loop.
Output: Redis-adapter-backed gateway + an activated Kafka consumer routing alerts to clients.
</objective>
