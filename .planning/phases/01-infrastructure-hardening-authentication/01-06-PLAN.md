| backend → sso.egov.uz | client_secret + PINFL exchange with the external identity provider |
| backend → PgBouncer → Postgres (+replica) | DB connections cross the pooling/replication layer |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan | ASVS |
|-----------|----------|-----------|-------------|-----------------|------|
| T-06-01 | Spoofing (CSRF) | OneID callback state | mitigate | Verify `state` against the HttpOnly `iduz_state` cookie (not a client body field); reject mismatch (RESEARCH AUTH-03 / Pitfall 6) | V51 |
| T-06-02 | Info Disclosure | OneID client_secret / PINFL | mitigate | Secret + PINFL exchange server-side only; credentials via ConfigService/Vault; remove `dev-client` default in prod | V6 |

| T-06-04 | Tampering / Repudiation | Stale reads from replica routed to auth/transaction paths | mitigate | Route ONLY analytics/leaderboard reads to the replica; auth/transaction reads stay on primary (replication-lag read-after-write bug) | V7 |
