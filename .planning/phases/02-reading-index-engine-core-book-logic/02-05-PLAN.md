The headline new artifact is `POST /libraries/:libraryId/transfers/:transferId/confirm`. The endpoint authorization is tight: only the librarian whose institution.directorId === userId for the source library (or a SUPER_ADMIN / TUMAN_ADMIN scoped to the right tuman) may confirm. Notifications fire to the return-library librarian on successful confirm so they know the inventory debt is closed.

Purpose: Roaming inter-library transfers cannot ship to users until the bilateral confirmation exists — without it, every roaming return silently corrupts the source library's inventory the instant the book leaves with the borrower.
