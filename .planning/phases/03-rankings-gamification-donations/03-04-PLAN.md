## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| StatsGateway broadcast → WebSocket clients | Any client can subscribe to `top100:{month}` public rooms; per-user `user:{userId}` rooms expose award events to the owner. Authorization on subscription is loose (room name is public knowledge), but payload is anonymized server-side. |
| Profile widget → /api/users/me/badges | JWT-protected; only the holder sees their own badges (BadgeService.getUserBadges takes user.sub from the JWT payload, not from URL). |
| Admin dashboard → /donate/admin/breakdown | Role-gated SUPER_ADMIN + BUXGALTER (Plan 03-03). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
