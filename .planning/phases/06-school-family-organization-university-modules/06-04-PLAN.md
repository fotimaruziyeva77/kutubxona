<objective>
Club CRUD (SCH-03) + Parent SMS consent token deep-link (SCH-04) + Debate
recording with MinIO file upload (SCH-05). The most security-sensitive plan
of Phase 6 because it touches: (1) under-18 PII flows via SMS; (2) public
consent endpoint with token; (3) file upload with MIME sniff + MinIO. All
infra primitives (MinioService, ClubMemberConsentToken model, DebateMedia
model) land in Plan 06-01. This plan wires them end-to-end.

Purpose: PQ-9 §8b mandates Jadidlar Izidan club operation in every school.
The platform is the digitization layer — but if parent consent leaks or
debate evidence is forged or file uploads are abused, the entire compliance
case collapses. This plan implements the three flows with adversarial care:
constant-time token compare, single-use consumedAt, MIME magic-byte verify,
50MB+4-file cap, signed URLs TTL ≤ 1h, audit log on every state transition.

Output: ~12 source files, ~50 new specs, 2 frontend pages, 3 new sub-services.
</objective>
