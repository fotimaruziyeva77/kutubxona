       - Injectable service implementing OnModuleInit, OnModuleDestroy.

       - onModuleInit: check KAFKA_BROKERS env. If unset, log warn and return (graceful no-op, same pattern as KafkaConsumerService).
       - If set: create Kafka client, create consumer with groupId "sifat-ai-audit".
       - Subscribe to topics: KAFKA_TOPICS.BOOK_BORROWED, BOOK_RETURNED, BOOK_RESERVED, READING_PROGRESS, ISBN_SCANNED, FRAUD_DETECTED, RI_UPDATED, TUMAN_RI_DROPPED.
       - For each message, call processAuditEvent(topic, message.value parsed as JSON).
       - processAuditEvent routes by topic:
         * FRAUD_DETECTED: create AiAuditLog with scope="USER", issueType="FRAUD_DETECTED", severity=CRITICAL, analysis from message data.
         * TUMAN_RI_DROPPED: call predictService.analyzeRootCauses(scopeId) to get root causes (AI-03 wiring), create AiAuditLog with scope="TUMAN", issueType="RI_DROPPED", include RCA results in analysis field, emit via gateway.emitNewAlert.

         * BOOK_BORROWED/RETURNED: aggregate in memory (sliding 1-min window); if a single user has >5 borrows in 1 minute, create AiAuditLog with issueType="RAPID_BORROW", severity=WARNING.
         * Other topics: log at debug level, no action.
       - onModuleDestroy: disconnect consumer gracefully.

| NLQ SQL templates -> Prisma | User question parsed to SQL execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-09 | Injection | NLQ SQL templates | mitigate | Parameterized queries via Prisma $queryRaw with tagged template literals; no string interpolation |
| T-07-10 | Denial of Service | Kafka consumer backpressure | mitigate | Consumer processes one message at a time; AiAuditLog writes are non-blocking; rapid-borrow window is memory-bounded to 1 minute |
| T-07-11 | Spoofing | Kafka message authenticity | accept | Internal Kafka cluster; no external producers in V1.0 |
| T-07-SC | Tampering | npm installs | mitigate | No new npm packages in this plan |
