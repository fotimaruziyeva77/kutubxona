## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DOKON_OPERATOR -> Store API | Operator manages only their own store (operatorId scope guard) |
| Public -> Store profile | Unauthenticated readers can view store profiles and product catalogs |
| SUPER_ADMIN -> Premium badge | Only super admin can grant/revoke premium status |
| Store webhook -> HMAC | External store systems authenticate via HMAC-SHA256 signature |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Spoofing | Store product CRUD | mitigate | operatorId ownership check on every mutation (createProduct, updateProduct, deleteProduct) |
| T-08-02 | Tampering | Product price/stock | mitigate | Zod validation on price (positive integer) and stockCount (non-negative) in DTO |
| T-08-03 | Elevation | Premium badge | mitigate | setPremiumBadge endpoint restricted to SUPER_ADMIN via RolesGuard |
| T-08-04 | Information Disclosure | Store profile | accept | Public endpoint by design — only active products shown, no operator PII exposed |
| T-08-05 | Denial of Service | Excel import | mitigate | 10MB FileInterceptor cap, streaming parser, BATCH_SIZE=100, BullMQ concurrency=2 |
| T-08-SC | Tampering | npm installs | mitigate | No new npm packages in this plan — uses existing exceljs, @nestjs/elasticsearch |
</threat_model>
