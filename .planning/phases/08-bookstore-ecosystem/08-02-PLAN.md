  <action>
    1. Add searchStoreProducts(dto: StoreProductSearchDto & { lat?: number; lon?: number }) to store.service.ts:
       - Build ES bool query against STORE_PRODUCTS_INDEX_NAME
       - must: multi_match on dto.q against fields ["title^3", "title.cyrillic^3", "author^2", "author.cyrillic^2", "isbn", "storeName"] with fuzziness AUTO
       - filter array:
         - { term: { active: true } } (always — only show active products)
         - if dto.storeId: { term: { storeId: dto.storeId } }
         - if dto.genre: { term: { genre: dto.genre } }
         - if dto.inStock: { range: { stockCount: { gt: 0 } } }
         - if dto.minPrice: { range: { price: { gte: dto.minPrice } } }
         - if dto.maxPrice: { range: { price: { lte: dto.maxPrice } } }
       - sort: if lat+lon provided, primary sort is _geo_distance on "location" field with order "asc" and unit "km", then _score desc, then premiumBadge desc (premium stores appear first at same distance); if no lat/lon, sort by _score desc then premiumBadge desc
       - size: dto.limit (default 20), from: (dto.page - 1) * dto.limit
       - Map hits to result objects including _source fields + distance (from sort values when geo sort active)
       - Wrap in try-catch with Prisma fallback: searchStoreProductsFallback

    2. Add searchStoreProductsFallback(dto): Prisma query on storeProduct with where: active=true, OR on title/author/isbn contains mode insensitive, price range, stockCount > 0 if inStock. Include store: { select: { name, slug, lat, lon, premiumBadge } }. No geo sort in fallback (return unsorted by distance).

    3. Add GET /store/products/search endpoint to store.controller.ts:
       - @Public() (readers search without auth)
       - @ApiQuery decorators for: q, storeId, genre, minPrice, maxPrice, inStock, lat, lon, page, limit
       - Calls searchStoreProducts

    4. Create store-search.spec.ts with:
       - Mock ES client (search method)
       - Test: search with q="Alpomish" returns hits with title, price, stockCount, storeName
       - Test: search with lat/lon adds _geo_distance sort to ES query
       - Test: search with minPrice=10000 maxPrice=50000 adds range filters
       - Test: search with inStock=true adds stockCount > 0 filter
       - Test: premiumBadge stores appear before non-premium at same relevance
       - Test: ES failure falls back to Prisma search (no throw)
